# KnowTrace 公开离线演示语料

这里包含 **20 篇官方 FastAPI 中文 tutorial Markdown**，以及配套的 **100 条评测草稿**。文件下载完成后，导入、检索与来源校验都可以离线进行。

## 来源与许可

- 上游仓库：<https://github.com/fastapi/fastapi>
- 固定提交：[`8e3db5153ec314d6e7775cd0ea39a46e95bfddb0`](https://github.com/fastapi/fastapi/commit/8e3db5153ec314d6e7775cd0ea39a46e95bfddb0)，对应 release 0.162.1 的提交。
- 来源目录：`docs/zh/docs/tutorial/`。
- `documents/` 保存上游文件的原始 UTF-8 字节，未替换文本、未翻译或扩写。
- 原始 MIT 许可证完整保存在 [LICENSE](LICENSE)。准确的许可证来源 URL、SHA-256，以及每篇文档的源路径、raw URL、浏览 URL、提交、字节数和 SHA-256 均见 [manifest.json](manifest.json)。
- 上游 Markdown 可能引用其他页面、图片或 `docs_src` 代码片段；这些外部资源不在本包内。这里是供检索使用的固定文档语料，不是完整的离线 FastAPI 文档网站。评测证据均来自已收录的正文，不依赖未下载的代码片段。

## 离线核对与重新获取

在项目根目录使用 Python 3.10 或更新版本运行：

```console
python scripts/fetch_demo_corpus.py
```

默认模式只读取本地文件，核对 20 个文档和许可证哈希、来源约定，以及评测数量、拆分、每篇题数和所有可回答题的证据短引。不会请求网络、加载模型或执行上游代码。

只有显式指定 `--download` 才会从固定提交的 `raw.githubusercontent.com` URL 重新获取文件：

```console
python scripts/fetch_demo_corpus.py --download
```

已有同一提交的 manifest 时，重新下载的文件必须匹配原 SHA-256；不同来源或提交会被拒绝覆盖。`demo/.gitattributes` 禁止 Git 改写原始文档和许可证的换行符，以便 Windows 检出后仍能校验。

## 100 题的使用范围

[evaluation.json](evaluation.json) 的数据集 ID 是 `fastapi-zh-100`：

| 划分 | 可回答 | 无答案 | 合计 |
|---|---:|---:|---:|
| dev | 40 | 10 | 50 |
| test | 40 | 10 | 50 |
| 合计 | 80 | 20 | 100 |

每篇文档有 4 条自然改写的问题，其中 2 条属于 dev，2 条属于 test。每条可回答题都有一个准确的文档文件名和一段逐字证据短引；无答案题的这两项为 `null`。无答案表示**这些 20 篇文件无法支持答案**，不表示整个 FastAPI 文档或互联网都没有答案。无答案题包括未收录的相邻技术主题、缺少实现细节的相关问题，以及未提供的运行状态或私有信息。

**标签状态：AI 辅助编写、已逐条核对来源及证据存在的草稿，尚未经独立人工复核。** 这不是人工验证的行业基准，也不包含预设或虚构的性能数字。

- `source-check.json` 记录此次本地完整性与结构检查，以及被检查的 manifest 和评测文件哈希；它不是检索性能报告。
- 只将 `documents/` 里的 20 个文件用于知识库索引。不要索引评测问题、参考证据、manifest 或校验报告；不要把 gold labels 注入回答。
- dev 用于选择切块、检索、融合和拒答参数；test 应在参数固定后评测。这里按问题拆分，同一文档可出现在两个集合，不能据此声称对未见文档的泛化能力。
- 某些教程讲解内容存在重叠；当前每题只标记一个目标文档，没有穷举其他文档中的所有有效证据。文档命中率可能低估具有其他正确来源的结果。
- 当前问答只支持离线检索与证据摘录评测，不衡量 LLM 生成质量、事实综合、多跳推理或生产级业务成功率。
- 文档内容固定在所选提交，可能包含演示性实现和特定版本行为。使用者应保留上游许可和来源，并在作正式基准或简历定量表述前独立复核标签、实际运行并保存原始结果。
